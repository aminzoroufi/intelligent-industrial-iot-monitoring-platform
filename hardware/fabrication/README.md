# NOT RELEASED FOR FABRICATION

Every file in this directory is a review artifact for revision
`A0-UNVERIFIED`. `fabrication-status.json` is authoritative:

- board routing is incomplete;
- ERC and DRC were not run because KiCad is unavailable;
- copper Gerbers intentionally contain no production routing;
- the STEP assembly uses project-authored component envelopes;
- no PCB order or assembly is approved.

Do not upload this directory to a fabricator. The expected future release set is
BOM, centroid/position CSV, top/bottom copper, solder masks, silkscreen, board
outline, plated/non-plated drills, schematic PDF, and component-accurate board
STEP, all regenerated by KiCad after the documented gates pass.
