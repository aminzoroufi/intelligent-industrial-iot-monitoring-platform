# Contributing

This is a personal portfolio repository and does not grant a license to create
or distribute derivative works. Discussion and defect reports are welcome, but
code contributions require prior written agreement from the maintainer.

For an agreed contribution:

1. keep changes focused and add evidence-based tests;
2. preserve SPDX headers and third-party notices;
3. do not commit credentials, private measurements, or generated caches;
4. run `make check` and document any hardware-only skips truthfully;
5. use conventional commit subjects.
